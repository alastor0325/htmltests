Does Web Audio activate the platform media controls? (bug 2067534)

Each row plays audio only through the Web Audio API (no media element) and configures navigator.mediaSession / navigator.audioSession differently. Click Run on a row: the previous scenario stops and the new one starts. At each checkpoint, answer whether the platform media controls show this page.

  • Chrome: "hub" is Global Media Controls (toolbar media button, or chrome://media-internals Audio Focus tab shows Controllable). "OS" is the system overlay (macOS Now Playing / Control Center, Windows media flyout, Linux MPRIS).
  • Safari / Firefox: the system overlay.
  • For "after PAUSE" checkpoints, press pause in the platform controls. If none are shown, use Simulate pause, which runs the page's pause handler code. Real presses that reach the page are listed under the scenario.
  • Cells marked italic are predicted from source code, not measured. Each run uses a fresh hidden same-origin iframe, so no Media Session state carries over between scenarios.
